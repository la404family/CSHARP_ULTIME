## 📖 À propos

Ce dépôt constitue la structure complète d'une formation C# destinée à former des développeurs full-stack sur l'écosystème Microsoft .NET. Il regroupe les cours théoriques, les projets pratiques progressifs et la documentation pédagogique au format LaTeX.

---

## 👤 Public cible

> Cette formation s'adresse à des **développeurs maîtrisant déjà un autre langage de programmation** (JavaScript, Python, Java, PHP…) qui souhaitent se reconvertir ou étendre leurs compétences vers l'écosystème .NET.

---

## 🎯 Objectifs de la formation

À l'issue de cette formation, l'apprenant sera capable de :

| Technologie | Compétence visée |
|---|---|
| **C# (Console)** | Maîtriser la syntaxe, LINQ, l'asynchronisme et les I/O |
| **SQL & Bases de données** | Modéliser des données et écrire des requêtes CRUD brutes |
| **ASP.NET Core** | Concevoir et sécuriser des APIs REST avec EF Core et JWT |
| **Angular** | Développer des SPAs consommant une API REST |
| **WPF** | Créer des applications bureau Windows avec le pattern MVVM |
| **.NET MAUI** | Développer des applications mobiles multiplateformes |

---

## 📚 Support pédagogique

Le contenu théorique est rédigé en **LaTeX** sous la forme d'un livre complet comprenant :

- ✅ Explications théoriques structurées
- ✅ Exemples de code commentés ligne par ligne
- ✅ Sessions de Questions / Réponses
- ✅ Style scientifique et professionnel
- ✅ Coloration syntaxique claire (thème *light*) pour les blocs de code
